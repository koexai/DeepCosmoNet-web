# 3D YOLO-like Detector for Cosmic Voids: Dataset and Model Documentation

## 1. Project Overview
This project implements a deep learning approach for identifying cosmic voids in Large-Scale Structure (LSS) surveys. [cite_start]It utilizes a 3D adaptation of the YOLO (You Only Look Once) object detection architecture to process voxelized particle density fields[cite: 48]. [cite_start]The method aims to reduce the computational burden of traditional void-finding algorithms while maintaining detection accuracy[cite: 48, 51].

## 2. Theoretical Framework
[cite_start]The core model processes 3D density fields derived from N-body cosmological simulations[cite: 97].

### 2.1 Architecture
[cite_start]The architecture uses a Feature Pyramid Network (FPN) to detect voids across multiple scales simultaneously[cite: 49].
* [cite_start]**Input:** $128^3$ voxel grids representing the 3D density field[cite: 98].
* [cite_start]**Backbone:** A custom encoder that feeds into the FPN[cite: 37, 215].
* [cite_start]**Heads:** Five multi-scale detection heads responsible for regressing void presence, coordinates, and radii[cite: 37, 56].

### 2.2 Key Innovations
* **Super-Separable 3D Convolutions:** To handle 3D volumetric data efficiently, the model uses decomposed convolution blocks. [cite_start]This reduces computational complexity from $O(C^{2}\cdot3^{3})$ to $O(C\cdot3^{3}+C^{2})$[cite: 57].
* [cite_start]**Physics-Informed Loss:** The training uses a composite loss function to handle class imbalance and geometric regression[cite: 246]:
    [cite_start]$$L_{tot}=\lambda_{\mathbb{P}}L_{\mathbb{P}}+\lambda_{xyz}L_{xyz}+\lambda_{R}L_{R}$$ [cite: 247]

## 4. Performance and Evaluation
[cite_start]The model was evaluated on DEMNUni simulations against ground truth generated by the Pylians Void Finder[cite: 59, 151].

### 4.1 Detection Metrics by Scale
The detector performs best on intermediate scales.
* [cite_start]**Intermediate Voids ($16-32 h^{-1}Mpc$):** 73% Precision, 63% Recall, 55% IoU[cite: 357].
* [cite_start]**Large Voids ($>32 h^{-1}Mpc$):** 9% Precision, 62% Recall[cite: 357].
* [cite_start]**Small Voids ($8-16 h^{-1}Mpc$):** 66% Precision, 43% Recall[cite: 357].

### 4.2 Void Size Function (VSF)
[cite_start]Despite some geometric inaccuracies in individual detections, the model accurately reproduces the Void Size Function (VSF), which characterizes the abundance of voids as a function of their radii[cite: 368, 370]. [cite_start]This suggests the method is robust for cosmological parameter inference relying on void abundances[cite: 379].

## 5. Usage
To load the sample dataset and filter for physically significant large voids (radius > 10,000):

```python
import pandas as pd

# Load data
df = pd.read_csv('sample_voids.csv')

# Filter for large voids (likely corresponding to > 10 h^-1 Mpc depending on units)
large_voids = df[df['radius'] > 10000]

print(f"Found {len(large_voids)} large voids.")
print(large_voids.head())
````
